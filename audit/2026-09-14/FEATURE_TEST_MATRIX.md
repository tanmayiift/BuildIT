# BuildIT feature and test matrix — 2026-09-14

This supersedes the earlier audit's closure claims. It describes the current patch, not deployed production behavior. Final combined results are recorded in PROJECT_AUDIT_REPORT.md. A source inventory or a passing mock does not count as a real external integration test. The latest local verification ran 1,970 tests in 223 files; browser and external integration limits below remain explicit.

Evidence levels: **DB** = Convex handlers exercised with simulated database inputs; **API** = a real local Convex process with simulated signed-in users; **component** = rendered React behavior with controlled responses; **contract** = real application code with an external service replaced; **live read** = production configuration observed without modification; **browser** = actual Chrome/CUA interaction against the isolated BuildIT services; **blocked** = required environment or permission missing. The supported CUA run completed 45 named browser cases. The full Playwright shell run remains blocked by macOS Chromium helper permissions; see `audit/evidence/e2e-shell-launch-limitations-2026-09-14.md`.

## Role boundary

| Operation | Viewer | Developer | Admin | Owner |
| --- | --- | --- | --- | --- |
| Read own active workspace figures/evidence | Yes | Yes | Yes | Yes |
| Read another workspace without membership | No | No | No | No |
| Start/cancel review, dismiss finding | No | Yes | Yes | Yes |
| Change repo policy, manage keys/trackers | No | No | Yes, recent sign-in where required | Yes, recent sign-in where required |
| Invite/manage members | No | No | Yes, bounded by owner safeguards | Yes |
| Change monthly capacity limit | No | No | No | Yes, recent sign-in |
| Set own notification preference | Yes | Yes | Yes | Yes |
| Read encrypted credentials or other users' sessions | No | No | No | No |

Four roles are simulated in authorization tests; two separate users/organizations exist in the local real server. Neither is evidence of adoption by a second real customer.
